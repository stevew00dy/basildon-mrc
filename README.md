# Basildon Model Railway Club

The official website for **Basildon Model Railway Club (BMRC)** — established 1979, Basildon, Essex.

## Live Site

[bmrc.uk](https://bmrc.uk)

## Dev

```bash
npm install
npm run dev
```

## Deploy

```bash
npm run deploy
```

Builds and publishes to GitHub Pages.

## Built With

- React
- Tailwind CSS v4
- Vite
- TypeScript
